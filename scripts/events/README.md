# 全国詩吟イベントナビの更新

公開ページは `/events/`。正本は `events/events.json`、表示は `scripts/events/render.py` で生成する。

1. `events/events.json` の催事を更新する。既存IDは変更しない。
2. `python scripts/events/render.py` を実行する。
3. `python scripts/events/check.py`、`node scripts/events/check-ui.cjs` を実行する。
4. ページ本体、データ、必要なスタイル・スクリプトを同じ更新として扱う。公開は既存のCloudflare Pages運用に従う。

週次の自動調査・更新は [WEEKLY_UPDATE.md](WEEKLY_UPDATE.md) に従う。毎週月曜9時（日本時間）のCodex予約から実行する。

## 過去の情報を残す方針（2026-09-16 指定）

- 保存対象は **2022年1月1日以降**の大会・コンサート・発表会。開催終了や年数の経過を理由に削除しない。「直近1年」へ掲載範囲を戻さない。
- 2022年からの過去分の追加調査は低優先。今後の催事の掲載・日時や会場の修正を優先し、その後に補完する。
- 2022-01-01～2025-09-15 の補完は未完了。`events.json` の `research_start: 2025-09-16` は初回調査の起点であり、保存期限ではない。古い記録を調査済みと誤認させるために書き換えない。
- 年ごとの開催日・会場・出典を確認して追加する。毎年開催されていることだけを根拠に、未確認の年の日程を補わない。中止・延期が判明した場合は通常の開催記録と区別して確認する。
- 古い観覧料・入場条件は、その回の情報として残す。現在の条件を過去の大会へ転用しない。
- 地図・カレンダー・過去の一覧は登録された開催日に基づくため、過去データを追加後に再生成する。補完作業の進捗は [BACKLOG.md](BACKLOG.md) に残す。

## 観覧と出場を区別する

- `admission` / `fee_status` は**観覧料**。出場参加費を入れない。観覧料が不明なら `admission: null`、`fee_status: "unknown"`。
- `fee_status` は `paid` / `free` / `unknown`。
- `audience` は `open`（一般向け観覧案内あり）、`contact`（非会員の申込・問い合わせ窓口あり）、`restricted`（関係者のみ）、`unknown`（不明）。有料・無料だけを根拠に見学可を推定しない。
- `audience_note` は来場者向けの案内、`audience_basis` は確認資料または運営者が判断した理由を残す。運営者判断で変更する場合はその日付と根拠を記録する。
- 開場・開演・終演予定は `open_time` / `start_time` / `end_time`（24時間表記）。不明は `null`。
- 開催日と開催県に不整合がある催事は、解消してから追加する。

## 出典・地図・日時

- `sources` に資料の名称、HTTPSのURL、主催者／会場／参加団体等の種類を残す。主催者の公開X・Facebook投稿も登録できる。投稿者が主催者かを確かめ、転載投稿だけで確定しない。
- Googleマップには県・市・会場名（住所が分かる場合は住所）を渡す。未確認の座標やPlace IDを作らない。
- 画面の「これから／過去」は閲覧時の日本時間で自動分類する。これは情報収集の自動更新ではない。`updated_at` と `checked_at` は実際に確認した日付に限って更新する。
- 開催予定の終了時刻が不明なため、開催当日は終日「本日の予定」と表示する。
- 調査時の確認待ち8件は公開データへ取り込んでいない。調査原本は `output/research/shigin-events-2026-09-16`（ポータルリポジトリの外）。

## 表示とナビゲーション

`page.template.html` と `events/events.css` / `events/events.js` がページ構成。共通ヘッダー・フッターは `tools/index.html` の共有マーカー内を生成時に取り込む。データ取得通信をせず、生成済みHTMLを絞り込むため、JavaScript無効時にも全件の本文と外部リンクを読める。

### 地図・カレンダー

- 初期表示は「これからの予定」で、日本時間の今月・来月。地図・カレンダー・一覧に終了分を混ぜず、別の「アーカイブス」タブから調べる。予定がない地域を選んでも自動で過去へ切り替えない。
- アーカイブスの月選択は2022年1月から現在まで。保存済み記録は経過年数で削除しない。予定へ戻ると現在の2か月へ戻る。過去の料金・条件は当時のものと案内する。
- 地方・都道府県の条件は地図の引き出し線、カレンダー、本文一覧に共通適用する。地方区分の正本は `events/regions.json`。47都道府県を重複なく11地方に分け、甲信越は山梨・長野・新潟、北陸は富山・石川・福井、三重は東海とする。
- 地方変更時に県の条件を解除し、県の選択肢をその地方だけに絞る。地図や催事名から県を選ぶと対応する地方も同期する。全国大会も開催県の地域情報に含める。
- 催事の詳細・日付・月の一覧を開いても「すべて」へ変えない。今後の催事は予定、終了した催事はアーカイブスとして表示する。月を動かすと、適用中の日付条件は移動先の月全体になる。
- URLの `view`、`period=past`、`region`、`prefecture`、`date`（日または月）、`month` を復元。旧 `period=all` は予定表示へ移行。過去の日付を指定したURLはアーカイブスへ案内する。不正日付や範囲外の値は採用しない。
- カレンダーは2か月を同時生成し、日付枠内に開催県と催事名を全件表示する。アーカイブスの終了分には「終了」を表示。同じ日の複数イベントも隠さない。狭い画面では月を縦に並べ、日付枠を横スクロールできる。
- `short_name` は地図・カレンダー向けの任意の略称。元の `name`・日時・出典は変更しない。未指定なら括弧書きを省いた名称を使用。詳細リンクの読み上げと本文には正式名称を残す。
- スマホの地図は番号付き県名と引き出し線を表示し、直下に同じ番号の予定カードをすべて表示する。PCでは予定カードそのものへ線を引く。ウィンドウ幅・フォント読み込み後の実寸で線を再配置する。
- 地図素材は `assets/maps/README.md` を参照。2026-09-17から地形に沿ったMIT素材へ変更。レンダー時は安全なパスだけを抽出し、SVG自体にも緑の塗り色を指定する。
- CSS/JSはレンダー時に内容のSHA-256から `events.<hash>.css/js` を生成して参照する。生成された2ファイルも公開に含める。クエリ文字列だけの変更では古いCSSが残る環境があるため、内容に応じてファイル名を変える。古いHTMLからの参照を壊さないよう、既存のハッシュ付きファイルは残す。
- 追加調査はリポジトリ外の `output/research/shigin-events-regions-2026-09-16`。2026-09-16の追加は27件、掲載県は25から36都道府県へ拡大。
