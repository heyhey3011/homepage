詩吟ちゃんねる 投稿ツールのプライバシーポリシー

Privacy Policy for the Shigin Channel Upload Tool

このページは、YouTube チャンネル「詩吟ちゃんねる」の運営者 heyhey が、自分のチャンネルのためだけに使う投稿ツールについての説明です。
This page describes a private tool that heyhey, the operator of the YouTube channel "Shigin Channel", uses only for the operator's own channel.

1. このツールについて / About this tool

「詩吟ちゃんねる 投稿ツール」（Shigin Channel Upload Tool、以下「本ツール」）は、運営者が自分のパソコンで動かす個人用のプログラムです。運営者が制作した動画を、運営者自身の YouTube チャンネル（詩吟ちゃんねる）にアップロードし、タイトル・説明文・サムネイル・再生リスト・字幕・コメントを設定します。また、チャンネルの分析データを読み取り、動画の振り返りに使います。

本ツールは一般には公開・配布しておらず、運営者以外は利用できません。他の人の YouTube チャンネルやアカウントにはアクセスしません。

The Shigin Channel Upload Tool ("the Tool") is a private program that runs only on the operator's own computer. It uploads videos produced by the operator to the operator's own YouTube channel and sets their title, description, thumbnail, playlist, captions and a comment. It also reads the channel's analytics so the operator can review video performance. The Tool is not published or distributed, is used by no one other than the operator, and never accesses anyone else's YouTube channel or account.

2. YouTube API サービスの利用 / Use of YouTube API Services

本ツールは YouTube API サービスを利用しています。本ツールを利用することにより、YouTube 利用規約に従うことになります。YouTube API サービスを通じて扱われる情報は、Google プライバシーポリシーにも従って取り扱われます。

The Tool uses YouTube API Services. By using the Tool, the user agrees to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

3. 扱う情報 / Information the Tool accesses

  • 運営者の Google アカウントの認証情報（OAuth 2.0 のトークン）
  • 運営者のチャンネルの基本情報（チャンネル名・チャンネルID）
  • 運営者の動画の情報（タイトル・説明文・公開設定・再生リスト・字幕・コメント）
  • 運営者のチャンネルの分析データ（視聴回数・視聴時間・登録者の増減など）

他の YouTube ユーザーの個人情報を集めることはありません。

The Tool accesses only: the OAuth 2.0 tokens for the operator's own Google account; the operator's channel name and ID; information about the operator's own videos (titles, descriptions, privacy status, playlists, captions and comments); and the operator's own channel analytics (views, watch time, subscriber changes, etc.). The Tool does not collect personal information about other YouTube users.

4. 利用目的 / How the information is used

扱う情報は、運営者自身の動画を投稿・設定すること、および運営者自身のチャンネルの状況を振り返ることだけに使います。広告やその他の目的には使いません。

The information is used only to upload and configure the operator's own videos and to let the operator review the performance of the operator's own channel. It is not used for advertising or any other purpose.

5. 保存と共有 / Storage and sharing

認証情報は、運営者のパソコン内に Windows の機能で暗号化して保存します。分析データや投稿の記録も運営者のパソコン内にのみ保存し、外部のサーバーには送りません。これらの情報を第三者に提供・販売・公開することはありません。

本ツールは、利用者の端末に Cookie を保存したり読み取ったりしません。

Authentication tokens are stored only on the operator's computer, encrypted with Windows' built-in per-user protection. Analytics data and upload records are also stored only on the operator's computer and are not sent to any external server. This information is never shared with, sold to, or disclosed to any third party. The Tool does not store or read cookies on any user's device.

6. 許可の取り消しと削除 / Revoking access and deleting data

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定（サードパーティ製アプリへのアクセス）からいつでも取り消せます。取り消した場合や本ツールの利用をやめた場合、運営者のパソコン内に保存した認証情報とデータは削除します。YouTube API サービスから取得したデータは、ポリシーで定められた期間を超えて保存しません。

Access granted to the Tool can be revoked at any time via the Google security settings page (third-party apps with account access). When access is revoked or the Tool is no longer used, the stored tokens and data on the operator's computer are deleted. Data obtained through YouTube API Services is not kept longer than permitted by the YouTube API Services Developer Policies.

7. 改定 / Changes to this policy

本ポリシーは必要に応じて改定します。改定した場合は、このページに最新の内容を掲載します。

This policy may be updated as needed. The latest version will always be posted on this page.
