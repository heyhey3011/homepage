# 都道府県地図

## 現行のイベントページ（2026-09-17〜）

`japan-geographic.svg` は [PA4KEV/japan-vector-map](https://github.com/PA4KEV/japan-vector-map) の `japan-prefectures.svg`。
作者: Kevin Matsubara / Copyright (c) 2023 / MIT License（全文: `japan-geographic-LICENSE.txt`）。取得日: 2026-09-17。

`scripts/events/render.py` が47都道府県の本体のパスを抽出し、緑の配色・検索リンクを付けて生成する。北海道と沖縄を含む。離島の一部を省略した開催地域の案内図であり、正確な距離・面積を示す用途ではない。
引き出し線は都道府県内の代表位置を示し、個別会場の位置ではない。会場案内にはイベントごとのGoogleマップを使う。
