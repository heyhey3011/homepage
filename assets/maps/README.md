# 都道府県地図

出典: https://github.com/lalamalink/japan-map-svg

作者: lalamalink / Version 2026.06.30 / CC0 1.0 Universal（LICENSE.txt）

元ファイルは `svg/deformed-japan-prefecture-map.svg`。取得日: 2026-09-16。
`scripts/events/render.py` が47都道府県のパスを読み込み、色・県名・検索リンクを付けてイベントページへ生成する。
地形を簡略化した案内用の地図。正確な距離・面積や行政境界を示す用途には使わない。
